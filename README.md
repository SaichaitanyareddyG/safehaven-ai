# SafeHaven AI

Patient-safety tooling for clinical staff: verify that the medication in hand
is the one that was prescribed, and turn discharge instructions into something
the patient can actually read — in their own language.

Two things drive the design. Medication verification has to fail loudly rather
than guess, and anything generated by a model has to be checked against the
source before a patient sees it.

## What's in it

- **Medication verification** — barcode scan (ZXing) against the prescribed
  product, with an image fallback when the barcode won't read and an explicit
  "unverified" state instead of an optimistic pass.
- **Patient instructions** — extraction, generation and translation through a
  provider interface, validated for completeness, fact preservation and
  translation fidelity before release.
- **Access control** — JWT auth behind an `AuthProvider` seam, so the dev
  provider can be swapped for Cognito without touching call sites.
- **Audit trail** — every read and write against patient data is recorded.

## Stack

**Backend** — FastAPI · SQLAlchemy 2 · Alembic · PostgreSQL · Pydantic v2 · pytest
**Frontend** — React · Vite · TypeScript · TanStack Query · shadcn/ui · Tailwind · ZXing
**AI** — provider interface over mock / OpenAI / Anthropic / Ollama

The LLM provider defaults to `mock`. The test suite reads the same setting, so
a real provider would otherwise make billed calls on every run.

## Running locally

```bash
# Backend
cd backend
cp .env.example .env          # fill in DATABASE_URL and JWT_SECRET_KEY
docker compose up -d          # Postgres
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload

# Frontend
cd frontend
npm install
npm run dev
```

## Tests

```bash
cd backend && pytest          # unit + integration
```

Integration tests run against a real Postgres database rather than mocks — a
mocked database will happily accept a migration that production rejects.

## Notes

`STORE_RAW_LLM_DATA` is off by default: prompts and responses can contain PHI
and are not persisted unless explicitly enabled for local debugging.
